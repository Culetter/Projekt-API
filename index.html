Application API

REST API do zarządzania zamówieniami, produktami i użytkownikami. Zbudowane na FastAPI z autoryzacją JWT i bazą danych MySQL.

FastAPI MySQL SQLAlchemy JWT OAuth2 Pydantic pymysql
14 endpointów
5 routerów
5 modeli DB
RBAC autoryzacja
Wszystkie endpointy (oprócz /auth/, /auth/token i GET /products/{id}) są chronione tokenem JWT.
/auth Authentication
POST /auth/ rejestracja nowego użytkownika
POST /auth/token uzyskaj token JWT (logowanie)
/products Products
POST /products/ utwórz produkt
GET /products/{id} pobierz produkt po ID
PUT /products/{id} zaktualizuj produkt
DEL /products/{id} usuń produkt
/users Users
GET /users/{id} profil użytkownika
PUT /users/{id} zaktualizuj dane użytkownika
DEL /users/{id} usuń konto
/orders Orders
POST /orders/ utwórz zamówienie
GET /orders/{id} pobierz zamówienie
DEL /orders/{id} usuń zamówienie
/roles Roles
POST /roles/ utwórz rolę
GET /roles/{id} pobierz rolę
DEL /roles/{id} usuń rolę
